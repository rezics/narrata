## 结果

Goal 的"阅读"结果：Narrata 渲染选项、路径与状态，正文与选项文字经宿主的渲染插槽交还宿主
（REZICS 对应 `DocumentBody`）。接口不为 REZICS 特化（决定 1）。

1. **无界面的阅读器控制器**（`@rezics/narrata` 中，不依赖任何框架）：基于 `openBook` 的 `Book`
   与 `ContentResolver`，维护当前画面（`BookView`、按 `collectScreenContent` 收集并以同一上下文
   批量解析的内容、加载与错误状态）；动作有选择（单选与多选的最少、最多数，禁用原因）、沿路径
   回退（checkout）、重试；存档状态（保存中、已保存、写入失败或被另一标签页取代后重载）；
   每次画面更新后用 `nextContentUnits()` 预取下一步的正文。`unavailable` 与 `incompatible` 有
   明确状态，不泄露原因。
2. **React 绑定**（新子路径 `@rezics/narrata/react`，`react` 为可选 peer dependency，不打进包）：
   一个阅读器组件，Narrata 渲染选项、路径与状态，宿主通过插槽渲染正文段与选项文字（以及标题等
   其他内容引用），插槽收到内容引用、解析结果与上下文。无样式或只带可覆盖的类名与 CSS 变量；
   键盘可操作，选项与状态有合适的 ARIA 语义。
3. **参考阅读器改用它。** `examples/gamebook-web` 用 React 组件与控制器替换自己的选项、路径与
   存档状态逻辑，插槽用它现有的本地内容渲染；保留它特有的部分（作品导入、调试面板等）。现有
   浏览器回归继续通过，并补上插槽、多选、禁用原因、`unavailable` 与回退的浏览器测试。
4. **安装测试与预算。** tarball 安装测试覆盖新子路径（Vite 构建中使用 React 组件）；首屏仍只请求
   清单与首块；JS 预算按新子路径分别计量并说明余量。

## 约束

- 不做图视图、服务器存档同步、作品升级、创作接口；阅读器为它们留出状态与插槽位置即可，不提前
  实现。
- 不改 Rust、Wasm 或任何格式；运行时缺少需要的调用时在交接中提出。
- 新依赖（如 `@testing-library/react`）写进交接，由 manager 记入工具链（并行任务正在改工具链页）；读者首屏不得引入 React 之外的运行时依赖。
