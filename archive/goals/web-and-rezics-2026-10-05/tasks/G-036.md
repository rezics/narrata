## 结果

完成 Goal M2 的作品演化规划、描述符发布挂接、只读影响评估及公开 authoring/server 评估/应用接口。
先读 ADR 0023、已合入的 history::evolution 与 Session assess/apply，以及公共 authoring 句柄和生成类型。
复用 kernel/节点迁移协调器；不再实现迁移框架，不把 stable ID 当作语义兼容证明。

1. planEvolution 从受检的前后作品与作者恢复声明生成/检查 EvolutionDescriptorV1，保持 MigrationId、
   排序/预算/声明冲突/墓碑身份等既有语义。内容实际修订/别名不换逻辑构件时走 Exact；不可依据 ID 相同
   擅自判 Automatic。所有需确认、不可应用、旧版继续的结果由已实现核心产生。
2. 现有发布集合接收可选的受检演化描述符对象，按 ADR 0022/0023 的 evolution 角色及身份挂接；
   编写/读取都核实源/目标构件与 descriptor identity，不接受只写一个 claimed digest。重新发布/多跳链
   和无 descriptor 的旧发布继续可读，现有冻结语料字节不变。若必须超出现有 ADR 的格式，先交接新 ADR
   需求，不直接修改已冻结格式。
3. 公共 @rezics/narrata/authoring 及其 server 入口从独立安装包完成评估、显式确认、应用与冲突处理。
   计划绑定 cursor、源/目标 artifact、descriptor、比较预算与结果；确认期间目标/游标/状态改变使确认失效。
   明确 Exact/Automatic/NeedsConfirmation/旧版继续/不可用，不把失败吞成普通打开。输出字节与 Rust 核心一致，
   读者按需导入 authoring 才执行 trace；reader 首屏不引入该模块。
4. 有界、只读影响评估作业接受宿主授权枚举的存档头/对象加载器，逐项调用同一核心并汇总脱敏结果；
   不自行读取数据库/枚举其他用户、不为作者泄露读者状态，不写回存档。资源限额与缺对象得到明确结果。
5. 提供框架无关的确认/应用控制器或最小模拟宿主，让宿主能展示报告、确认或继续旧版，并在保存确认后
   显示已升级。阅读器产品接线若触及另一个任务认领路径，交接具体调用点，由 manager 协调；不能绕过互斥。

验收至少包括 ADR 的内容/别名修订、未走路径规则变化、路径分歧、有损根恢复、浅历史、提议 ID、
多次迁移、多跳、确认失效、CAS 冲突及未知写入不丢旧进度。新用例从现有演化 corpus 读取，并在独立
tarball 的 Node/Bun/浏览器能力上复现代表性旅程；不要只导出 Rust 类型而没有可调用路径。

在线会话任务会修改 nodes-wasm、Web runtime/online/reader/react、安装/预算脚本及包配置；本任务不修改
这些共享入口。authoring-wasm、authoring 模块与纯 Rust 演化规划可独立推进；需要最终安装脚本、预算或
阅读器组合时在交接中给出小的明确集成变更，manager 在两者结束后统一接线。不要为了并发新造一套入口。README 由 manager 统一更新，本任务用公共调用测试表达用法并在交接提供最小示例。
