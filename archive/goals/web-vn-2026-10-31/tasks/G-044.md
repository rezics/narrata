## Native capability

- Expose a narrow Rust API over the current checked Session/safe point, carrying exact
  artifact and Commit provenance. External unchecked State cannot silently establish a
  checked current interaction. Pure helper types/functions can remain internal as appropriate.
- Return potential dependency references, not predicted committed story states. A conservative
  union is acceptable and must be documented as such. Preserve source role information
  useful for media preparation; references remain host-owned content identities, no bytes,
  URLs, authorization or decoded handles.
- Current Advance and visible enabled choices must produce meaningful bounded next refs.
  Follow automatic Scene/Branch/Mutate/Call/Return flow to the next interaction using the
  existing checked semantics. Do not enumerate all multi-select combinations or traverse
  the entire work; conservatively union applicable targets. Do not claim exact branch/args
  results when assignments, conditions or call context were not evaluated. Unsupported or
  unresolved dependencies must remain explicit rather than quietly omitted as complete.
- Track full visual replacement and Music Keep/Play/Stop intent while collecting candidate
  media. Include dialogue text/speaker/voice and choice prompt/labels as applicable. Do not
  invent a choice speaker or turn potential data into an actual rendering instruction.
- Bound visited locations, graph/object loads, candidates and output references with checked
  limits; stop before doing work beyond the bound. Expose completeness/truncation/unknown
  conditions clearly. Cycles/recursion, missing chunks and corrupt data cannot look like an
  ending or successful complete projection. Preserve actual source errors and exact object
  identities; an unavailable source is not proof that an object does not exist.
- Loading graph cache data is allowed; do not call durable Advance/Choose, mutate narrative
  State, active refs, history, storage, visits or external effects. Cache/pin ownership must
  remain bounded and release normally. No whole-work scan to build the bounded result.

This is an in-memory Rust query: do not add Serialize/JSON exchange, new object kinds,
source/State/Input/Commit/checkpoint formats, schemas or compatibility corpus files. Existing
formats and frozen bytes stay identical. A future public bridge can version/freeze its own
exchange boundary after actual consumer needs are known. Report concrete evidence to the
manager if the result genuinely requires changing that scope.
