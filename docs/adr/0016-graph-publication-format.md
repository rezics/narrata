# ADR 0016：发布时图瓦片与语义摘要

状态：Accepted（2026-10-05）。补充 [ADR 0013](0013-r2-text-free-node-format.md) 为分析保留的
kind code；不改变节点、运行时或存档格式。

## 决定与理由

图是程序的发布时投影。几何与内容标签分开，既能独立缓存，也使 `narrata-graph` 无须依赖
节点格式或内容解析器。宿主读取的是固定整数列，不需要逐行创建 JavaScript 对象。

| kind（schema 1） | 输出 |
| --- | --- |
| `0x0120` | 瓦片索引：三种细节层级、瓦片 object id 与包围盒、作者簇到瓦片的映射、簇的世界坐标平移 |
| `0x0121` | 作品级瓦片：作者簇与跨簇关系，使用紧凑概览坐标 |
| `0x0122` | 簇级瓦片：分区与区间关系，使用簇内坐标 |
| `0x0123` | 节点级瓦片：节点与边，跨区端点由 ghost 行补齐，使用各行所属簇内坐标 |
| `0x0124` | 保留给标签表（`NodeId` → ADR 0013 `ContentRef` 标题）；由 R2 适配任务定义形状 |

前四种对象使用 kernel 的 [规范 CBOR](0003-deterministic-cbor-profile.md) 与信封。
对象以 `object_id(kind, schema, payload)` 的 64 位小写十六进制加 `.cbor` 命名。
索引引用同一身份；信封内的 SHA-256 只校验载荷，不代替 object id。
字段编号、整数宽度和行形状由 [wire 编解码器](../../packages/narrata/tooling/crates/narrata-graph/src/wire.rs)
与 [冻结语料](../../fixtures/compat/graph-v1/manifest.json) 固定。

瓦片的列是 CBOR byte string：16 字节 ID 逐行拼接；坐标为小端 `i32`，簇与端点索引、
节点标记、边分类计数为小端 `u32`，作者顺序为小端 `u64`，其余列为 `u8`。
边分类计数每行固定五项，顺序为 choice、next、conditional、call、return。
不引入压缩协议、可插拔编码或 JSON 瓦片。

索引的簇按 ID 排序；瓦片按层级、归属簇、分区、序号排序。每个簇映射到作品瓦片与自己的
簇级、节点级瓦片。包围盒包含 ghost 行；作品级框使用概览坐标，其他框使用世界坐标，
由行内局部坐标加该行所属簇的 `i64` 平移得到。空作品瓦片没有框。
坐标沿用布局的整数单位（横向步长 32、纵向步长 64），读取方不重新布局。

语义摘要使用版本 JSON：`format_version: 1`、`artifact_id`、入口、结局与分类、每个结局
可达的簇集合，以及按连续作者簇压缩的公共瓶颈序列。`artifact_id` 是可空的 64 位小写
十六进制构件 object id，由产品适配器附加；图 crate 不推断构件身份。
节点与簇分别用 `node:` / `cluster:` 加 32 位小写十六进制表示。JSON Schema 从
[Rust 类型](../../packages/narrata/tooling/crates/narrata-graph/src/summary.rs) 生成，保存在 crate 内。
摘要只说明结构可达性，不证明分支条件可行，也不推断实体事实。

## 身份、读取与演进

改变任何瓦片载荷（ID、行顺序、坐标、归属、分类、重要性、标记、作者顺序、端点或计数）、
kind 或 schema 都改变其 object id。改变索引的身份引用、框、映射、顺序或平移也改变索引
身份。标签或正文变化不进入这些载荷；它们只有在适配器改变结构输入时才影响几何身份。
摘要 JSON 不参与瓦片或索引的摘要，填充 `artifact_id` 也不改变几何身份。

受检读取首先验证信封的版本、kind、schema、长度和载荷 SHA-256，并对照请求的 object id；
之后执行规范 CBOR 往返、精确字段集合、字节与集合预算、行数和列长度检查。拒绝越界的
簇、端点与瓦片索引、未知分类或标记、不一致的边计数与掩码、无序或重复身份、错误的层级
归属、索引映射与包围盒。节点瓦片保持 2,000 个节点加边的预算。
JSON 读取拒绝未知或重复字段、错误身份、版本、顺序、重复集合项和未压缩的瓶颈段；
实现为输出设置显式字节预算，超限返回错误，不截断事实。
单对象检查证明投影良构与引用身份，不证明它与原程序语义相同；发布方用结构输入重建验证。

这是首个可分发图格式。旧内存对象和基准 `.columns` 缓冲不是存储协议，没有旧分发格式
需要迁移。schema 1 与 JSON version 1 的读取路径和冻结测试永久保留；未来格式改变使用
新 ADR、版本、新语料与明确读取或迁移路径，不重写本语料。
