## 结果

`main` 上的 GitHub Actions（`.github/workflows/ci.yml`）每次推送都失败，从未通过。交付前 CI
必须通过（Goal 约束）。本任务修复已知原因，让每个平台都能报告结果：

1. **Windows 换行。** `gamebook-r1 (windows-latest)` 的 `cargo fmt --all --check` 报
   `Incorrect newline style`（如 `crates/narrata-core/src/diagnostic/error.rs`、
   `packages/narrata/nodes/crates/narrata-nodes/src/error.rs`）：runner 签出时 autocrlf 把文本
   转成 CRLF，而 `rustfmt.toml` 要求 `newline_style = "Unix"`。在 `.gitattributes` 顶部加
   `* text=auto eol=lf`，让工作区总是 LF；文件中已有的 `-text`/`binary` 规则写在后面，仍然覆盖
   冻结语料与二进制构件。确认 `git add --renormalize .` 不改动任何冻结语料；如有源文件以 CRLF
   存在索引中，作为同一提交的规范化列出。`windows-latest` 的 `gate-g3` 也失败了，查它的日志确认
   是同一原因或另行修复。
2. **goalctl 测试的路径。** `docs-and-scripts (windows-latest)` 的 `bun test scripts` 中 5 个
   lifecycle 测试失败：临时仓库在 `C:\Users\RUNNER~1\AppData\Local\Temp\...`（8.3 短文件名，
   与 `D:` 上的检出不同盘），`dispatch` 把简报路径算成
   `../../../../../RUNNER~1/.../docs/goals/alpha/tasks/G-001.md`，于是报
   "briefs live at docs/goals/<goal>/tasks/G-NNN.md"。修正 `goalctl` 的路径规范化（两侧都取
   真实长路径，或相对仓库根解析），并加一个用短文件名或 junction 临时目录复现的回归测试。
   同一运行中 `refuses overlapping Goals…` 测试期望的文字也没出现，查清是否同源。
3. **让所有平台都报告。** 矩阵加 `fail-fast: false`；ubuntu 与 macOS 的 job 之前都被取消，
   从未得出结果。用 `gh run list`/`gh run view --log-failed` 查历史运行（只读），能看到的其他
   失败一并修复；看不到的在交接中说明。

## 约束

- 不推送，不触发远程运行；`gh` 只做只读查询。修复靠本机复现证明：例如
  `git clone -c core.autocrlf=true <主 checkout> <临时目录>` 后跑 `cargo fmt --all --check`；
  临时目录放在 `.temp/` 下或系统临时目录，结束后删除。
- 最小修改：不重组 workflow、不加新 job、不升级 action 或工具版本。
- 改 workflow 时，`docs/development/toolchain.md` 中的记录若受影响就同步修改（该文件无人认领，
  做最小修改并在交接中列出）。
