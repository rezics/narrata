## 结果

补齐 REZICS 解析正文与选项文字所需的 Narrata 一侧（[决定 4](../../../product/decisions.md#4-内容引用协议与内容方无关)、
[内容引用](../../../contracts/content-references.md)、[REZICS 集成](../../../integrations/rezics.md#解析与结果)）：

1. **解析上下文。** 契约要求远程内容方的解析上下文带宿主对译本或版本的选择（`realization`）
   与对 Narrata 不透明的读者身份（`viewer`），`content-resolve-request` 现在只有语言偏好。按契约
   补上，保持 `ok`/`unavailable`/`incompatible` 三种结果；本地内容方忽略它们。同一画面的正文与
   选项文字用同一个上下文。先确认这些 schema 是否被冻结语料覆盖：被覆盖就停下，在交接中把它
   作为需要 ADR 的阻碍报告；没有覆盖就作为向后兼容的可选字段加入，并说明理由。
2. **下一步预取。** 宿主需要知道读者下一步可能进入的内容单元，以批量预取正文（REZICS 的 R8）。
   给 `narrata-nodes` 增加从当前视图求"一步之内可能呈现的内容单元"的函数，经 Wasm 暴露为单独的
   调用，不改 `BookView` 的形状；结果只含内容引用，不含未揭示节点的其他信息。测试覆盖局部回应、
   分支、多选和调用。
3. **TypeScript 解析接口。** 在 `@rezics/narrata` 中定义宿主实现的批量解析接口（请求、上下文、
   三种结果的类型，由 schema 生成或与之核对），以及按画面收集引用、按宿主上限分批的辅助函数。
4. **模拟 REZICS 内容方。** 作为 `@rezics/narrata/testing` 子路径导出：以 Occurrence IRI 为 key，
   带块 ID（`attrs.id`）的扁平块序列，多个译本（保留原文块 ID，缺译本回退原文语言），撤回后返回
   `unavailable`，不存在与无权限同样返回 `unavailable`，缺少段落端点的译本返回 `incompatible`，
   选项文字按标签 ID × 译本保存，并能导出 `ContentOutline`。用示例作品"山口来信"的内容建一份
   模拟数据。它是后续模拟宿主验收与 REZICS 测试的样例，不是产品代码路径。

## 约束

- 最小实现：不做阅读器外壳、渲染插槽或 UI（后续任务）；不改 R2 构件、存档或 `BookView` 的形状。
- 并行任务正在改 `narrata-nodes` 的 `compile.rs`、`check.rs`、`registry.rs`、`source.rs`、`lib.rs` 与
  `runtime.rs`，不要碰它们；需要在 `lib.rs` 导出新函数时，在交接中列出要加的一行，由 manager 合入。
- 契约页只在实现改变了它描述的事实时更新，并缩短为代码说不了的部分。
