## 结果

Goal 的"图"结果中的作者视图（[决定 12](../../../product/decisions.md#12-图视图预先计算并分层交付)、
[图与分析](../../../contracts/graph-and-analysis.md#作者视图)）。读者地图依赖关系投影，是后续任务。

1. **瓦片的受检读取**（TypeScript，在 `@rezics/narrata` 的新子路径 `@rezics/narrata/graph` 中）：
   读取 [ADR 0016](../../../adr/0016-graph-publication-format.md) 的瓦片索引、三层瓦片与标签表
   （kind `0x0120`–`0x0124`），按该 ADR"身份、读取与演进"一节做受检读取：信封、`object_id`、
   规范 CBOR 往返、精确字段、列长度、索引与归属一致性、预算，拒绝时给出明确错误。与 Rust
   `narrata-graph` 的 `wire.rs` 对照，用冻结语料 `fixtures/compat/graph-v1/` 与
   `products/gamebook-demo/story.graph/` 测试：每个对象都能读出，篡改一个字节、错误身份或越界
   索引都被拒绝。复用包内已有的 CBOR 与摘要代码，不另写一套。
2. **作者视图**：sigma.js + graphology，动态 import 懒加载，不进入阅读首屏。三层细节：作品级
   瓦片（作者簇与跨簇关系）→ 进入某簇看簇级瓦片 → 进入分区看节点级瓦片；坐标直接用瓦片中的
   整数坐标，不在浏览器里重新布局。同时绘制的节点与边受上限约束（契约：约 5 万节点、15 万
   边；可配置），超出时只显示上一层。节点标题经标签表的内容引用由宿主的 `ContentResolver`
   批量解析，未解析的显示占位，不显示 ID 以外的推测文字。按需取瓦片（宿主提供
   `fetchObject(id)`），已取对象缓存在内存中、有上限。提供框架无关的挂载函数和一个 React 组件
   （沿用 `@rezics/narrata/react` 的可选 peer 约定）。
3. **参考阅读器**：把现在约 120 节点上限的 SVG"结构图"换成作者视图，读取示例作品已发布的图
   对象；浏览器测试覆盖三层切换、标题解析、绘制上限与懒加载（首屏不请求 sigma 与瓦片）。
4. **体积**：图子路径单独计量预算，阅读首屏预算不变；tarball 安装测试覆盖新子路径。

## 约束

- 不做读者地图、关系投影、编辑能力（"局部编辑的富节点编辑器"不在第一阶段）或 cosmos.gl 星图。
- 不改 Rust、Wasm、瓦片格式或冻结语料。
- 新依赖（sigma、graphology 及其版本与许可证）写进交接，由 manager 记入工具链。
- 契约页在实现后缩短为代码说不了的部分。
