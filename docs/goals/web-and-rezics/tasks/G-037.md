## 结果

完成 Goal M2 的 visits、读者地图、关系查询与 PostgreSQL 参考装载，并从正式 npm 包调用。
依赖三项全部关闭后才认领共享绑定、生成类型、构建与图入口；不与它们并改路径。先读 ADR 0022/0023、
现有 runtime::trace、history::evolution、CheckedRelations/read_relations、参考 DDL 及 G-034 的公开句柄。
复用同一执行和校验核心，不新增地图执行器、数据库框架或宿主认证协议。

1. 受检存档祖先派生 visits：核对提交、State、Input、状态与摘要，按执行顺序调用已有只读 trace，
   从 history::evolution::audit 复用或提取共用受检重放，让演化比较与 visits 使用同一审计过程，
   不复制第二套祖先验证器。
   事件包含自动控制节点、局部/多选回应、branch、call/return、结局正文及动态提议。不得仅遍历等待位置，
   不把预取或结构可达计为访问。默认只含当前 cursor 的祖先；回退排除另一分支，显式合并多个 cursor
   保留各自来源。跨迁移保留每段 artifact/cursor 归属并验证迁移证据，不把旧 artifact 的节点/边搬到
   新投影；缺祖先/旧构件、截断或超预算返回明确 incomplete/缺失项，不宣称完整历史。
2. 同一 Rust 核心生成 readerMap：核对 artifact/投影版本；只输出已揭示单元、访问节点、实际走过且
   两端已揭示的边、已到达结局和当前受检 visible frontier。两个已访问端点不证明走过其间边；单元内
   转移来自 trace。可见 disabled 选项可作占位，未揭示目标只含交互已公开的 OptionId/labelRef/enabled；
   递归输出不得泄漏隐藏目标 ID、内容 key、标题、锚点、坐标、数量、路线集合、簇大小或作者布局。
   按首次访问顺序紧凑分配有限整数坐标，追加访问不重排；动态提议可贡献呈现引用，不冒充静态节点。
3. 保持 CheckedRelations/read_relations 对完整、稠密、规范分片集合的严格校验。为授权后的查询结果
   另建受检稀疏子集类型，使用 visits 派生的 allowlist 验证成员、引用闭包、artifact/版本、顺序、重复
   与预算；保留原 edge_no，不重新编号，也不把 SQL 的任意数组强转为完整投影。查询只取允许的
   单元/节点及正反向边和所需闭包，不把全投影、作者瓦片或标签表发送给地图客户端。
   公共关系适配还提供精确 artifact/version 下按内容引用、节点/簇、结局/route、结构 first 与正反向边
   的有界查询；first/route 沿用结构含义，不声称是读者首次访问或可行剧情路线。完整作者查询与
   visits 约束的读者查询分清类型，宿主授权决定可调用哪一个。
4. G-034 的 Publication 只有对象字节入口，尚无关系行入口；补有界 Rust-backed 关系访问器、逐片
   受检读取和数据库行重组校验，生成公开类型。装载器接受受检完整投影句柄；SQL 解码后的 unknown
   行回到 Rust 校验，TypeScript 只做驱动边界与参数映射，不重写投影语义验证。禁止一次巨大 JSON
   或数字数组搬运全作品。authoring/server 可生成完整投影及 visits/map，reader 首屏仍无 trace。
5. PostgreSQL loader 复用现有 TransactionalSql 与权威 relations-v1.sql，宿主安装 DDL、提供已授权
   连接。将现有 SqlParameter 边界补为可表达 null/boolean 的驱动参数并测试映射，不通过字符串伪造
   SQL NULL 或布尔值。完整事务内按依赖顺序只插入不可变行，提交后才可查询；相同 artifact/version/index 重试须
   核对所有行与列完全相同，缺行/多行/异值不能因 index 相同被接受。不同 index 同键拒绝，失败全回滚；
   并发同投影幂等、冲突投影拒绝，A/B 可并存且查询绑定精确 artifact。无需修改现有 DDL 或自动迁移。
6. 从独立 tarball 在 Node/Bun 和浏览器 Worker 调用公共接口，并在参考体验展示已揭示地图。
   覆盖自动/调用/局部/多选/结局/提议、循环、回退、浅历史、迁移来源、坏存档与预算、disabled frontier，
   以及隐藏值递归扫描、未走过边、稀疏 edge_no/闭包攻击。SQL 覆盖完整行比对、缺片/坏引用拒绝、
   中途故障、双连接竞争、仅插入权限及 A/B 隔离；查询结果与完整受检投影过滤出的允许结果一致。

依据 ADR 0022 新增 fixtures/compat/reader-map-v1 下的地图输出冻结语料及确定性生成入口，重复生成
须逐字节相同；在 .gitattributes 为新目录设置 -text，校验摘要、公开占位与防泄漏结果。所有既有
冻结语料保持只读，不重新生成或改写。沿用 ADR 0022 的地图/visits 交换形状与既有 schema；若实际
需要超出 ADR 的格式先交接决定。正文与标签由宿主解析；客户端 visits 不能充当授权或奖励证明。REZICS 需求只
在交接列出能力请求，由 manager 归入集成文档。README 只写调用/生命周期/宿主授权职责，不复制类型表。
