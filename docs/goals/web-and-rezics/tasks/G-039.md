## 结果

完成当前 Goal M2/M3 的阅读器组合接线。公共演化任务已明确交接 reader/runtime 历史构件挂接需求；
API 控制器、独立 Node/Bun/浏览器测试不能替代读者在真实参考体验中的确认、应用与旧版继续。
依赖顺序使在线、演化、地图和维护的共享路径先收敛；先读当前公共接口再做最小组合，不另造迁移框架。

维护已在 ffc0f966 合入并验收，包含完整历史 pack 注册与当前精确根重开；应复用而非
重做该接缝。源码复核 `.temp/review-history-registration.md` 记录的剩余责任仍在本任务：历史名字
不能丢弃，Session 切到 A 后 NodeBook 的 program/pack/analysis/nextContentUnits/reload 及 loader
必须一致；完整 pack 探针不证明旧 manifest/chunks 的按需加载，省略 timeline/identity/analysis
的对比和终态相等也不证明历史回退后继续选择。接续时按实际主线核对，不把完整 pack 路径当成已完成历史懒加载。

1. Reader 在当前构件 B 上重开跨迁移历史时，可按每个提交的精确 artifact 加载历史程序与必要块，
   复用 Session::register_history_program/open_with_registry 等已有机制。跨 A/B 时间线呈现、checkout、
   后续选择及保存使用该提交的程序和名字表/内容上下文；不能把 B 的 chunk loader 用于 A，不能总取
   作品当前发布。缺历史构件/块与坏存档可区分，保留原持久进度并允许重试，不伪造可读历史或结局。
2. 增加必要的薄 Wasm/Runtime 接缝和异步加载重试，保持现有 Book/OpenBook/旧 raw 入口兼容，
   首屏与活跃缓存有界。历史程序也按需受检装载，不为注册一个旧程序而无条件下载整部旧作品。
   复用已有 artifact source/loader 类型；不复制 RuntimeBook、不新增通用运行时工厂。reader 不引入
   trace、编译、布局或后台维护工具，评估/地图计算仍按既有 authoring/server 边界按需调用。
3. 在已验收的公共创作/在线参考旅程中接入演化提示：Exact、Automatic、NeedsConfirmation、
   不可迁移、缺对象、旧版继续分别有可执行动作。展示报告后再显式确认；游标/目标/预算改变使
   确认失效。迁移只在持久确认后显示已应用；未知结果、CAS 冲突、关闭/账号切换仍保留旧持久旅程。
   保留核心再次评估与 CAS，不在 UI 中重算迁移语义或自行把稳定 ID 当兼容证明。
4. 验证同一库中 A→B→再发布/迁移、历史 A/B 回退再选择、刷新重开，以及有损/分歧/浅历史确认。
   演化后地图只显示各 artifact 实际揭示的路径，维护导入/浅恢复不绕过当前页面上下文检查。
   不通过丢弃历史、总重开最新版或截断成单构件快照来规避跨版本呈现要求。
5. 以独立 tarball 的真实参考页面走桌面/移动端完整旅程，记录本次源码/包校验和、Wasm 请求身份、
   程序块与失败恢复；测试必须操作实际公开入口与可见动作，不仅检查 detached 控制器状态。

该任务只组合已交付能力。若某个薄接缝确需改变持久/交换格式，先提出 ADR 与旧读取路径；
不更改冻结语料、不修改 REZICS，不把宿主真实联合验收说成已完成。README 仅写宿主怎样调用和
管理生命周期，契约页只留意图/策略；类型、schema、代码与测试承载实际保证。
